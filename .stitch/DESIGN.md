# Subart 디자인 시스템

## 1. 시각 방향

홈은 밤의 서가다. 대표 작품의 표지 속 보름달, 우체국 창문, 붉은 우편함에 시선이 머물도록 탐색과 설명은 짙은 녹색 바탕에 둔다. 서가의 작은 책은 같은 표지를 정사각과 가로 판형에 맞게 각각 구성한다.

내 서재에서는 독자가 마지막으로 읽은 회차와 문단을 먼저 찾는다. 종이색 바탕에 회차 숫자, 읽은 위치, 이용 가능 상태가 순서대로 보인다. 커뮤니티는 작가의 개정 소식과 독자의 답을 편집란처럼 나란히 놓고, 좁은 화면에서는 편지와 답글 순서로 읽는다.

## 2. 팔레트와 역할

| 역할 | 색 | 쓰임 |
| --- | --- | --- |
| 숲 그늘과 서가 패널 | #101b16, #1c2c23 | 홈 배경과 추천작 설명 |
| 밝은 잎과 먹 | #d4e7b9, #172b1e | 어두운 화면의 첫 화 읽기 버튼과 버튼 글자 |
| 종이와 잉크 | #faf9f4, #202a23 | 밝은 화면 기본 배경과 본문 |
| 진녹색과 연녹색 | #19513c, #edf2e9 | 이어읽기 버튼, 읽는 중인 회차와 진행 막대 |
| 편지지와 적갈색 | #ede6d5, #78432f | 커뮤니티의 첨부 작품과 글쓰기 동작 |
| 잿빛 녹색 | #59655a, #d6dcd1 | 작가·회차 메타데이터와 구분선 |

현재 탭에는 밑줄 또는 윗줄과 선택 상태를 함께 둔다. 읽는 중인 회차에는 숫자와 ‘읽는 중’을 표시한다. 구독·권리·신고의 상태는 글로도 읽을 수 있어야 한다.

## 3. 글꼴

한글 UI는 Apple SD Gothic Neo와 사용 가능한 시스템 고딕, 작품명과 소설 본문은 AppleMyungjo와 시스템 명조를 사용한다. 영문 Subart 로고와 회차 숫자에는 Georgia 계열의 세리프를 쓴다. 대표 작품명은 데스크톱에서 최대 77px, 작은 화면에서 39~56px이다. 독서 본문은 약 18~22px, 행간은 모바일 1.92배, 큰 화면 2.08배다.

## 4. 구성 요소

- **탐색**. 독자 탭은 홈, 내 서재, 커뮤니티 순서다. 창작자 작업실과 운영 콘솔은 상단의 작업 공간에서 연다. 작품 검색은 제목·작가·장르를 찾는 대화상자다. Escape로 닫고 원래 버튼으로 돌아간다.
- **작품 표지**. 홈 대표 이미지는 화면 폭에 맞춰 초점을 조정한다. 작은 서가에서 책갈피 버튼은 배경과 독립된 원형 표면을 사용한다. 저장한 상태는 채워진 책갈피로 표시한다.
- **이어읽기**. 진행 막대, 숫자, 마지막 회차를 한 덩어리로 놓는다. 같은 공개 버전의 문단으로 재개하고, 버전 변경은 본문 위 안내에서 알린다.
- **커뮤니티**. 발행 날짜와 작품 신고를 작가 메타데이터에 묶는다. 편지 봉투 표식 아래에 개정 이유와 원문을 놓는다. 피드백 신고는 독자의 글에 속한다.
- **입력**. 필드 이름과 안내를 입력 영역 밖에 유지한다. 확인 동작은 하나의 주 버튼으로 두고, 요청 후에는 접수·검토·완료 상태를 해당 화면에 남긴다.

## 5. 배치와 기기

1440×900에서는 홈의 설명과 표지가 약 47:53으로 마주 본다. 본문 최대 너비는 1304px이다. 서재는 최근 작품과 회차, 커뮤니티는 작가와 독자, 작업실은 탐색과 현재 업무에 각각 두 열을 쓴다. 700px 이하에서 독자 메뉴를 하단으로 옮긴다. 760px 이하에서는 상세·작업 화면의 열을 접고 창작자·운영자 메뉴를 선택 목록으로 전환한다.

iPhone 15 Pro 기준은 세로 393×852 CSS 픽셀이다. 홈에서는 표지 아래에 제목과 읽기 버튼을 배치한다. 기본 좌우 여백은 20px이고 하단 탭은 안전 영역을 포함한다. 호버 없이 저장·읽기·신고가 가능하고, 키보드 초점과 모션 줄이기 설정을 유지한다.

## 6. Stitch 편집 지시 예시

- **홈**. 데스크톱의 넓은 서가에서 간이역, 온실, 돛배 전체가 보이게 구성한다. 모바일에서는 기존 정방형 표지를 유지하고 첫 화 읽기를 제목 가까이에 둔다.
- **내 서재**. 독자가 재방문하면 읽던 작품의 작가, 회차, 문단 진행률과 이어읽기를 같은 시야 안에 배치한다. 저장한 다른 작품의 제목은 별도 목록에 둔다.
- **커뮤니티**. 개정 소식과 원문을 바로 연결한다. 작품 신고는 작가와 날짜 옆에, 피드백 신고는 해당 댓글 옆에 둔다. 작은 화면에서 피드백까지의 세로 거리를 점검한다.

기준 구현은 같은 폴더의 HTML과 CSS다. 편집 후 두 기준 크기에서 표지 초점, 현재 탭, 버튼 이름, 본문 줄바꿈과 하단 탭 겹침을 확인한다.
